# Rush Hour / Pocket Racer

Un pequeno juego arcade de autos inspirado en las consolas portatiles de 8 bits. Esquiva el trafico mientras la velocidad aumenta.

## Ejecutar

Abre `index.html` en un navegador moderno. No requiere instalacion, dependencias ni servidor local.

## Controles

- Flechas izquierda/derecha o teclas A/D: cambiar de carril.
- P o espacio: pausar o reanudar.
- Espacio o Enter: iniciar o volver a jugar.
- En pantallas tactiles, usa los botones de la consola o toca el lado al que quieres moverte.

## Archivos

- `index.html`: estructura de la pagina y pantalla del juego.
- `css/styles.css`: estilos y adaptacion a pantallas pequenas.
- `js/game.js`: movimiento, trafico, colisiones y marcador.
